# Rational logarithms: AI-generated proofs and Lean formalization

This repository contains an AI-generated mathematical proof and Lean formalization of the claimed result: for every positive rational number `r ≠ 1`, `log r` is irrational and its irrationality exponent is `2`. The strict approximation statement is defined independently in [`Round2MainReference.lean`](lean-oai017/portable_project/Round2MainReference.lean):

```lean
def StrictRationalLogMain : Prop :=
  ∀ r : ℚ, 0 < r → r ≠ 1 →
    ∀ ν : ℝ, 2 < ν → ∃ Q : ℕ, ∀ q : ℕ, Q ≤ q → 0 < q →
      ∀ p : ℤ, (q : ℝ) ^ (-ν) <
        |Real.log (r : ℝ) - (p : ℝ) / (q : ℝ)|
```

The candidate theorem is `RationalLogReview.Main.strict_rational_log_main`; the fuller `rational_log_main` also states irrationality and the exponent equality. In particular, the claimed result would determine the irrationality exponent of `log 2`.

**Authorship and review status.** The mathematical proof, Lean code, and verification reports were generated by AI systems. `Zhuying` initiated and curated the project; this credit does not claim human authorship of the mathematical derivation. The work has **not been reviewed by human mathematical experts**. The supplied Lean checking records are described below, including their trust boundary; they do not establish expert review, novelty, or priority.

**Relation to OpenAI OAI017.** This work extends the interpolation and determinant methods in [OpenAI's OAI017 code](https://github.com/openai/math/tree/adc7f1241b42e322a6451854ab7e4b4c146bf78a/lean/OAI/NumberTheory/PiExponent). It directly reuses the function-field obstruction, persistent normal comparison, ordinary Rees blow-up arguments, parameter asymptotics, and determinant collisions. The original interpolation configuration has all multiplicative coordinates `Y = 1`, injective additive coordinates, and two volume conditions. This work uses pairwise distinct nonzero `Y` and arbitrary additive centers, with a total-volume condition. The constant-`Y` case reduces the curve estimate to one center; the arithmetic estimates also account for the height of the rational base. This is a recognizable extension of that method, not a derivation from scratch, and it does not assume the upstream theorem about `π`.
