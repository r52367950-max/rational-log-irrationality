# First-release preparation

The proposed first release is `v1.0.0`. No release, Zenodo record, or DOI is
claimed by these preparation files.

Before publication, review the English README and confirm these choices:

- Public curator name: `r52367950-max`, the project initiator and curator.
- Mathematical proof, Lean code, and review reports: generated by AI systems.
- Review status: not reviewed by human mathematical experts.
- Original code and verification metadata: Apache-2.0.
- Original prose and manuscripts: CC BY 4.0; upstream material retains its
  original licenses and notices.
- Citation version: `1.0.0`; update `date-released` in `CITATION.cff` to the
  actual release date before publishing if it differs from the prepared date.

## GitHub and Zenodo

1. Merge the publication-preparation PR after reviewing the files, and make the
   GitHub repository public when the curator approves publication.
2. Sign into Zenodo through GitHub. Open the GitHub integration settings and
   enable this repository before creating the release. Review any authorization
   requested by Zenodo; the integration installs a release webhook.
3. On GitHub, create release `v1.0.0` from the reviewed commit and publish it.
4. Check Zenodo's GitHub integration page for the archive and its real DOI.
   Add that DOI to `CITATION.cff` and add the corresponding DOI badge to the
   README; do not add a placeholder badge or an invented DOI.
5. Refresh the manifest and run `python helpers/verify_delivery.py .` after
   changing citation or README files.

Zenodo makes a best-effort attempt to read root-level `CITATION.cff` metadata.
If `.zenodo.json` is added later, its metadata overrides the citation file for
Zenodo. This project therefore prepares a citation file and no competing
Zenodo JSON file.

Suggested release description:

> First source release of the AI-generated rational-logarithm proof and Lean
> formalization extending OpenAI OAI017 methods, with provenance, verification
> records, and explicit authorship and review-status disclosures. The work has
> not been reviewed by human mathematical experts.

- [Zenodo: citation-file metadata](https://support.zenodo.org/help/en-gb/24-github-integration/96-how-does-a-citation-cff-file-affect-metadata-of-my-github-release)
- [Zenodo: integration permissions](https://support.zenodo.org/help/en-gb/24-github-integration/127-which-github-permissions-do-you-request-and-why)
- [Zenodo: managing records](https://help.zenodo.org/docs/deposit/manage-records/)

Zenodo currently permits self-deletion of records published less than 30 days
ago, and allows metadata such as title and authors to be edited after
publication. It should still be treated as a public archival release; verify
the current policy before relying on deletion or corrections.
